● CT Speak-It

Voice dictation for every build. Click into any field below, then hold Ctrl+Space and speak — or tap the mic in the corner. Press Esc to cancel.

Text is inserted at your cursor position, so you can dictate mid-sentence.
Same API used by editors like Quill, Slate, and ProseMirror.
  1. Copy src/speakit.js into the project (or serve it from one shared URL).
  2. Add <script src="speakit.js"></script> before </body>.
  3. Optional: deploy api/format.js once and add data-format-endpoint="https://…/api/format" for AI cleanup.
