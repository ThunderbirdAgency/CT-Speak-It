Ready for your first dictation?

  1. Allow microphone access.
  2. On Mac, allow Mockingbird in System Settings → Privacy & Security → Accessibility for automatic paste.
  3. Click a text field in another app.
  4. Press your dictation shortcut, speak, and press it again.

Some secure fields block automatic paste. Your words are copied to the clipboard so you can paste manually.

Make it feel natural.

For example: CommandOrControl+Shift+Space. Select text first, then use the rewrite shortcut and speak an instruction. Review before applying.

Memory also needs to be enabled in your account. This setting does not authorize recording or save transcripts to the server.

Recording starts only on activation and stops after three minutes at most. Dictation never executes CRM commands.

A second chance for your words.

The last recording is held in memory for retry. It is replaced by your next recording and discarded when you quit.

Retry a rewrite with the original text still selected in the target app. The result will be shown for review.
