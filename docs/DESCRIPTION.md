# Mockingbird

Your words. Your voice. Without the typing.

A Thunderbird voice tool for agents: desktop dictation, reviewed rewrites, exact spoken saved responses, and an optional writing memory you can inspect and edit. Pro is $15 USD/month or covered by a Thunderbird gift code. Gift access unlocks the same features without a card or automatic paid renewal.

The consumer release does not execute CRM/calendar actions, record meetings, listen for a wake phrase or install a native mobile keyboard. See LAUNCH-STATUS.md for deployment and installer availability.
